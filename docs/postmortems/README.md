# Post-mortems

One file per break, named `round-<id>.md` (for example `round-1.md`). The site bundles these at build time and shows each one on that round's Library page.

Suggested sections: **The attack** (quote the winning message), **Why it worked**, **The fix**, **What to copy into your own skill**.

Raw HTML in these files is not rendered. Write plain Markdown.
